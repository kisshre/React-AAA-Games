# 🎮 React AAA Games

A modern gaming website built with **React.js** and **Vite**, designed to provide a clean and interactive user experience for exploring AAA games.

## 📌 About The Project

**React AAA Games** is a frontend web application developed using React.js. The project focuses on building a responsive and visually appealing gaming interface while practicing modern React development concepts.

This project was created as part of my learning journey in **Frontend Development and Full Stack Development**.

## ✨ Features

* 🎮 Modern gaming-focused user interface
* 📱 Responsive design
* ⚡ Fast performance using Vite
* 🧩 Reusable React components
* 🎨 Interactive and clean UI

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/kisshre/React-AAA-Games.git
```

### 2. Navigate to the project

```bash
cd React-AAA-Games
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in browser

Vite will provide a local development URL, usually:

```text
http://localhost:5173
```
